# AI 自动操盘、策略自进化与实盘分级接管系统架构设计说明书

## 一、项目概述与战略目标

本系统旨在实现从当前“虚拟仿真操盘”向“全流程 AI 无人值守交易、双层策略自进化与最终实盘账户分级接管”的稳步演进。系统在严格遵守中国 A 股交易制度（T+1、整手、真实税费滑点）与极限制约风控（单票上限、总仓位上限、大盘暴跌熔断）的前提下，通过盘中节律执行与盘后沙盒多因子回测进化，实现长期稳健的 Alpha 超额收益。

---

## 二、理解锁定与核心原则 (Understanding Summary & Assumptions)

### 1. 核心目标与范围
- **执行闭环**：盘中交易节律自动巡检买卖，盘后数据回测与操盘军规复盘自进化；
- **进化对象**：量化超参数（因子权重、止损止盈比例）与自然语言操盘军规（Trading Skills）双层协同进化；
- **接管路径**：坚持“L0 虚拟双轨 -> L1 模拟达标考核(30天胜率/回撤) -> L2 手机端一键授权实盘报单 -> L3 全托管带急停断电”的渐进式演进；
- **非目标**：不追求毫秒级日内高频炒单（HFT），严格聚焦于日线至 15 分钟级别的高胜率波段趋势。

### 2. 核心假设与约束
- 盘中执行遵循 A 股标准交易时间（09:30 - 15:00），非交易日自动进入低功耗休眠；
- 算力分配上，全市场 5565 支粗筛与盘中轻量巡检由本地 Pandas/NumPy 向量化引擎完成，大模型仅在形态裁决与收盘复盘中按需介入；
- 任何情况下，单日账户净值回撤超 3.0% 或大盘跌幅超 2.5% 时，触发系统级强行风控熔断。

## 五、核心功能模块与接口规划

### 1. `AutonomousScheduler`（无人值守交易调度器）
- 职责：常驻后台守护，按交易日历分发定时事件；
- 关键任务节点：
  - `09:30` 开盘检查与数据预热；
  - `09:35` 早盘进攻建仓与冲高止盈；
  - `10:00 - 14:40` 每 15 分钟执行 `execute_auto_selling`；
  - `14:45` 尾盘建仓与次日跨日持仓确认；
  - `15:30` 收盘全天交易复盘与生成进化战报；
  - `20:00` 历史数据沙盒自动回测与超参数调优。

### 2. `SandboxOptimizer`（历史数据沙盒优化引擎）
- 职责：提取近 1 年股票历史日 K 线数据，对量化交易超参数进行网格寻优；
- 优化变量：硬止损比例（-4% ~ -8%）、动态止盈目标（+8% ~ +15%）、多因子权重（动量/换手/估值）、单票仓位上限；
- 目标函数：`Fitness = Sharpe_Ratio * (1 - Max_Drawdown) * Win_Rate`。

### 3. `SkillEngine`（操盘军规动态胜率管理与进化）
- 职责：管理军规从诞生、应用、考核到淘汰的完整生命周期；
- 规则：
  - 新军规初始胜率评分 75 分；
  - 每次被匹配使用后，根据该笔平仓真实收益动态调整胜率评分；
  - 得分低于 70 分或连续 3 次亏损的军规自动转入“失效归档”；
  - 前 5 条高胜率军规注入大模型 Prompt 进行重点参考。

### 4. `SafetyController`（风控与急停熔断中枢）
- **大盘指数暴跌熔断**：三大指数跌幅超 2.5% 自动禁止开仓；
- **单日回撤熔断**：账户净值单日回撤超 3.0% 冻结新交易；
- **数据中断防护**：连续 3 次拉取盘口失败自动挂起，绝不盲目下单；
- **全局急停开关 (Kill Switch)**：桌面端与移动端一键物理急停，终止所有调度与报单。

## 六、分阶段落地路线 (Roadmap)

1. **第一阶段 (Milestone 1)**：无人值守调度器与盘中交易节律自动闭环，双端提供自动托管开关与执行流水看板。
2. **第二阶段 (Milestone 2)**：盘后历史数据沙盒回测引擎与超参数自动调优管线。
3. **第三阶段 (Milestone 3)**：军规动态胜率淘汰体系与 L1 模拟达标考评看板。
4. **第四阶段 (Milestone 4)**：实盘接口抽象（QMT/MiniQMT）与 L2 手机端一键授权/L3 全自动接管。
